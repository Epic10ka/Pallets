## About

I developed this pallet counting software to improve and speed up pallet counting operations at work.  
The system helps organize counts efficiently while practicing programming logic, data structures, and file handling with JSON.

----

## Concepts Applied

- Exception handling
- Modularization using functions
- Data persistence with JSON
- Dictionaries and data structures
- Terminal interface organization

----

## Features

- Count CHEP pallets
- Count broken pallets
- Count export pallets
- Count slip sheets
- Display summary reports
- Reset all stored data

----

## Technologies

- Python
- JSON

----

## Objective

Improve problem-solving skills and gain practical experience in software development through a real-world automation project.

---

## How to Run

1. Clone this repository

```bash
git clone https://github.com/Epic10ka/Pallets
```

2. Navigate to the project folder:

```bash
cd pallets_counting
```

3. Run the program:

```bash
python_pallets.py
```
